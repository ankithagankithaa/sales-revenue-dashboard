Sales & Revenue Analysis Dashboard

Project Overview
This project focuses on analyzing sales and revenue data using Microsoft Excel. The dashboard provides insights into product performance, revenue trends, and category-wise sales distribution through interactive charts and key performance indicators (KPIs).

Objectives
*Analyze sales and revenue data.
*Identify top-performing products.
*Track revenue trends over time.
*Visualize category-wise sales contribution.
*Create an easy-to-understand business dashboard.

Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
GitHub

Dashboard Features
Total Revenue KPI
Total Quantity Sold KPI
Product-wise Sales Bar Chart
Revenue Trend Line Chart
Category-wise Sales Pie Chart

Steps Performed
Collected and organized sales data.
Created Pivot Tables for analysis.
Generated charts using Pivot Charts.
Designed a dashboard sheet.
Uploaded project files to GitHub.

Outcome
The dashboard helps users quickly understand sales performance, revenue growth, and category contributions. It demonstrates basic data analysis and visualization skills using Excel.
